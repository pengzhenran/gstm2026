使用
----
1. 本机预览：http://127.0.0.1:4173/wechat/article.html
2. 公众号后台：新建图文，打开 article.html 后全选复制，粘贴到编辑器。
3. 公众号编辑器通常不会自动搬运本地图片，请在对应位置重新上传：
   fig-orbit.png / fig-water.png / fig-ice.png /
   fig-cooccur.png / fig-domain.png / fig-alluvial.png
4. 封面使用 cover_900.jpg（或 cover.jpg）。
5. 标题、摘要可直接用文末的备选标题与摘要。
